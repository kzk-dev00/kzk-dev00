私はフリーランスのWebエンジニアです  
Vue / React を中心としたフロントエンドエンジニアです  
最近はGoとAWSでバックエンドにも取り組んでいます  

https://pins-share.com/
これは私が開発したアプリです
- 地図にピンを設置できカテゴリを設定できます
- カテゴリを他者に共有することができるのでおすすめのお店を新入社員さんなどに共有できます（共有された側はメモの編集が不可）
- 駅のQRコードからカテゴリを読み取らせれば観光地、お店を地図に表示でき視覚的に距離や場所はわかります。また、QRコードのURLは「共有した側」が任意に変更するまで変わらないのでカテゴリに属するピンの編集も後から可能です


### 使用技術
- フロントエンド：Next.js（React／TypeScript）
- バックエンド：AWS（Lambda／Go／API Gateway／DynamoDB）
- リポジトリ：https://github.com/kzk-dev00/pins
